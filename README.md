# Target Marks Calculator
Find the internal and end-sem marks you need for the grade you want.

Live demo: (add your link after Step 6)

## Features
- Choose your marks pattern and how the end-sem paper is converted
- See the marks to aim for, and what happens if you score less or more
- Clear messages when a target isn't possible
- Optional SGPA estimate, light and dark themes

## Assumptions
10-point grade scale with editable cutoffs. It works for one subject at a time.
